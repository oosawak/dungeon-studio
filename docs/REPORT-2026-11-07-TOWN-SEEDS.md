# 町のシードとランダム生成 — 2026-11-07

従来の町は川・道路・16棟の配置が固定され、シードは木や建物の幅・高さの一部だけに使われていた。地形と建物を共通のシードから計画し、川の左右・蛇行、街路、建物の位置・サイズ・屋根・高さを変えるようにした。同じシードでは同じ町を生成する。既存のMarkdownの保存形式は変更しない。

World・Town・Dungeonの生成設定に「ランダムに生成」を追加した。新しいシードを表示して生成する。シード指定による再生成とundo/redoを併用できる。スマホで非表示だった生成設定も開けるようにした。初期表示・場所変更・読み込み・undo/redo後のシード表示を実際のマップに合わせた。

町の再生成時に帰還入口が消える問題を修正し、接続する室内を維持する。ランダム化の検証中に見つかった、特定シードのWorldで出口が山に重なる問題も、出口までの草地を確保して修正した。

- 単体テスト12件。シード再現性、異なる配置、Markdown往復、202種類の町で全建物の入口への到達性、複数のキャンペーンの接続・ランタイム変換を検証。
- 別途1000種類の町で整合性と入口への到達性、100種類のキャンペーンで整合性を確認。
- `playtest-generation.mjs`: 3画面のランダム生成、再現、シード表示、undo/redo、帰還入口、Markdown保存、スマホ操作。
- `playtest-campaign.mjs`: 新配置で通常ゲームの町・家・ワールドと2ダンジョンの往復。
- `playtest.mjs`: 既存の編集操作と実WASMの鍵・扉・階段・落とし穴・戦闘・iframe等。
- `playtest-fps-travel.mjs`: 新しいサンプルの配置から歩行経路を求め、FPSの町・家への出入りと状態保持を検証。
