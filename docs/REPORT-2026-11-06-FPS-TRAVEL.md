# FPSの家への出入り — 2026-11-06

引き継ぎ検証後の開発として、FPS内で町から家へ入り、歩き、町へ帰還できるようにした。エディターで作成・接続したマップをそのまま使う。関連リポジトリやRust/WASMは変更していない。

## 実装

- 地図の `portal` をFPS座標へ変換。青い入口の枠と足元のリングを描画し、近づくと行き先とFキーの案内を表示する。Eのグラップル操作はそのまま。
- Fで現在地の近くの入口から移動。`$return` は訪問履歴をたどる。遠い入口、地上から高さ2mを超える場所、帰還先がない入口、ポーズ中のFでは移動しない。
- 場所ごとに描画グループ・衝突形状・位置・視点・敵・弾痕・Waveを保持し、帰還・再入場で復元する。非表示の場所の敵とWaveは停止する。再訪問時に形状を重複生成しない。
- HP・弾薬・スコア・FPS/TPS選択は移動先へ引き継ぐ。移動時は入力・速度・グラップルを解除し、移動直後の走り出しや射撃を防ぐ。
- 現在地名と編集画面へのリンクを更新。エディターは `startLocation` を尊重し、室内から戻ると同じ部屋を編集できる。
- `fps-journey.js` はマップの接続と帰還履歴のみを管理する。移動・戦闘の責任は既存FPSランタイムに残す。

## 検証

- `npm test`: 全9件成功。座標変換、入場・帰還履歴、元データを変更しないこと、単独マップでの帰還抑止を追加。
- `scripts/playtest-fps-travel.mjs`: 実ポインターロック・WASD・Fで入場→室内移動→帰還→再入場。距離制限、位置・視点、HP・弾薬、敵数・弾痕・Waveの保持、ポーズ中の入場抑止、形状数、編集場所を検証して成功。16棟の実サンプルでも道路をWASDで歩いて「旅人の家」へ入り、帰還する試験が成功。
- `scripts/playtest-atlas.mjs`: 町編集と既存FPS/TPSの移動・ジャンプ・射撃・リロード・視点切り替えの回帰試験が成功。
- 画像で入口の案内、室内のTPS表示、帰還後の描画を確認。

ブラウザー検証はローカルHTTPとGoogle Chrome、Playwrightで実施。各スクリプトの出力先に証拠画像を保存する。READMEのコマンドで再実行できる。

## 残る範囲

これはFPS内の場所の移動と一時的な状態保持であり、dungeonloadとの進行共有や永続セーブではない。鍵・扉・階段・地下階・落とし穴の統一、NPC・店・宿、壁登りと全身アニメーションは未実装。既存FPSのドローン戦闘と簡易建物描画を継続して使っている。
